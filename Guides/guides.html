Steward Library

These guidebooks accompany the Continuum Charter. They are designed for field use—practical, clear, and durable. Stewards, learners, and keepers can reference them independently as needed.

Start with the Learner’s Path if you’re new. Use the Field Manual and Case Anthology when you’re working through real scenarios.

Interactive Tools

These tools offer quick, real-time reflections aligned with Charter principles. They are lightweight, fast, and designed for field decision support when you don’t have time to flip through a full guide.

  • Steward’s Oracle

    Ask a question and receive a concise red / yellow / green style reflection, using Charter-aligned lens logic. Not prophecy, not a guru—just signal to help you steady your next move.
